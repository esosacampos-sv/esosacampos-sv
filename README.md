# Hola, soy Elsa Sosa

Soy desarrolladora de software con experiencia en aplicaciones de escritorio, sistemas empresariales, integración de datos y automatización de procesos.

Trabajo principalmente con tecnologías Microsoft, especialmente C#, .NET, WPF, SQL Server y desarrollo de soluciones internas para operaciones, reportes y procesos administrativos.

## Tecnologías

- C# / .NET Framework / .NET
- WPF / MVVM
- SQL Server
- REST APIs
- Entity Framework
- Git / GitHub / Azure DevOps
- Excel / ClosedXML
- Integración de datos y automatización de procesos

## Experiencia destacada

- Desarrollo y mantenimiento de aplicaciones empresariales para el sector farmacéutico.
- Diseño de módulos para actualización de datos, validación, historial y control de cambios.
- Desarrollo de herramientas para generación y validación de archivos EDI.
- Experiencia construyendo soluciones internas desde cero para automatizar procesos operativos.

## Proyectos

### PortEdiHub
Aplicación de escritorio desarrollada en .NET para procesar archivos Excel y generar archivos EDI CODECO para movimientos de contenedores.

**Tecnologías:** C#, .NET, WPF, ClosedXML, JSON templates.

### Server Updater
Sistema interno para gestión, revisión y actualización de información de productos farmacéuticos, con historial de cambios, validaciones y carga masiva de datos.

**Tecnologías:** C#, WPF, SQL Server, APIs REST.

### Compliance Module
Módulo para manejo y validación de medicamentos, impresión de reportes, reglas de negocio y mejoras de experiencia de usuario.

**Tecnologías:** C#, WPF, SQL Server, MVVM.
